## 2. Purpose

This document defines how the organization's Incident Response Program aligns with:

- NIST Cybersecurity Framework (CSF) 2.0
- NIST SP 800-61 Rev.2 (Computer Security Incident Handling Guide)
- NIST SP 800-53 (Security Controls)

This ensures structured, standards-based incident response governance.

## 4. NIST SP 800-61 Incident Lifecycle Alignment

The organization follows the four-phase model:

---

### Phase 1 – Preparation

- Incident Response Team defined
- Playbooks developed
- Tools configured
- Training conducted
- Threat intelligence integration

---

### Phase 2 – Detection & Analysis

- SIEM alert monitoring
- EDR investigations
- Threat intelligence enrichment
- Severity classification
- Incident declaration process

---

### Phase 3 – Containment, Eradication & Recovery

- Network isolation
- Account disablement
- Malware removal
- Vulnerability patching
- System restoration
- Integrity verification

---

### Phase 4 – Post-Incident Activity

- Root cause analysis
- Lessons learned session
- Control gap identification
- Detection improvement
- Reporting to management
