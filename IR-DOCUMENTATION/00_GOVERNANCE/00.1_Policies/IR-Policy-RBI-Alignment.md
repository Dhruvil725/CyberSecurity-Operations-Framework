## 2. Purpose

This document defines how the organization’s Incident Response (IR) framework aligns with:

- RBI Cyber Security Framework (2016 & subsequent updates)
- RBI Guidelines on Information Security, Electronic Banking, Technology Risk Management
- RBI Incident Reporting Requirements
- CERT-In Reporting Guidelines (as applicable)

This alignment ensures regulatory compliance for BFSI environments and MSSP-managed clients operating under RBI regulation.

## 3. RBI Cyber Security Framework – Core Requirements Mapping

---

### 3.1 Board & Senior Management Oversight

| RBI Requirement | Organizational Implementation |
|-----------------|-------------------------------|
| Board-approved Cyber Security Policy | IR Policy approved by CISO & Executive Management |
| Periodic reporting to Board | Quarterly security reports |
| Defined accountability | RACI Matrix documented |

Evidence:
- IR Policy (Master)
- Management Review Reports
- KPI Dashboard

---

### 3.2 Security Operations Center (SOC)

| RBI Requirement | Implementation |
|-----------------|----------------|
| Continuous monitoring | 24x7 SOC operations |
| Log monitoring | Centralized SIEM |
| Alert investigation | L1/L2/L3 tier model |
| Incident tracking | Ticketing system |

Evidence:
- SOC SOP
- SIEM Integration Map
- Alert Handling Procedures

---

### 3.3 Incident Response & Management

RBI requires:

- Formal incident response framework
- Defined reporting timelines
- Escalation procedures
- Root cause analysis

Implementation:

- Incident Severity Matrix
- Escalation Matrix
- Regulatory Communication SOP
- Post-Incident Review process

### 3.4 Incident Reporting to RBI

The organization ensures:

| Incident Type | Reporting Requirement |
|--------------|-----------------------|
| Major cyber incident | Report to RBI within defined timeline |
| Data breach | Notify regulator as per circular |

RBI reporting handled by:
- CISO
- Compliance Team
- SOC Lead
